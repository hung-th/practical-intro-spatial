Finding Henry Hung eating McDonald's

Henry is reported eating at McDonald's about 16 times a term. Where should you wait to catch him? Treat each sighting as a point and model the sightings as an inhomogeneous Poisson process: the intensity λ(s), the expected number of sightings per km², falls with the distance d(s) to the nearest restaurant.

log λ(s) = β₀ + β₁ d(s)

Is this pattern random?

Pick a process, then check it two ways. The quadrat test counts points in a grid of squares and compares the counts with what complete spatial randomness (CSR) predicts. Ripley's K, shown here as L(r) − r, asks how many other points lie within distance r of a typical point. The grey band is the range of 39 CSR simulations with the same number of points.

Moran's I and local clusters

Each square is an area with one value. Neighbours are defined by a weights matrix W: rook neighbours share an edge, queen neighbours share an edge or a corner. W is row-standardised, so the spatial lag Wz is the mean of a cell's neighbours. Moran's I is the slope of the line in the scatterplot of the lag against the value.

I = (n / S₀) · Σᵢ Σⱼ wᵢⱼ zᵢ zⱼ / Σᵢ zᵢ²,   zᵢ = yᵢ − ȳ

Things to try

  • Press "Shuffle values". The map keeps the same values in new places, and I falls to about E[I].
  • Set ρ below 0. Neighbours now tend to differ, like a chessboard, and I is negative.
  • Set ρ to 0 and count the local "clusters" before and after the correction. With 144 tests, about 7 are expected by chance alone.

Interpolation, cross-validation and the variogram

A smooth surface is measured with noise at a few sites. Predict it everywhere else, then judge each method by leave-one-out cross-validation: drop one site, predict it from the rest, and repeat for every site. In real data you never see the truth, so cross-validation is the error you can actually compute.
